# Code of Conduct

AgentSpec is an early-stage open-source project. We want it to be a professional, respectful place for people working on AI instruction engineering.

## Expected behaviour

Participants are expected to:

- be respectful and constructive
- assume good intent, while being clear about technical concerns
- keep discussion focused on the work and its impact
- welcome people with different backgrounds and levels of experience
- give and receive feedback professionally

## Unacceptable behaviour

Unacceptable behaviour includes:

- harassment, abuse, threats or discriminatory language
- personal attacks or sustained disruption
- publishing private information without permission
- sexualised language or imagery in project spaces
- bad-faith participation intended to derail the project

## Reporting

If you experience or witness unacceptable behaviour, please report it through the project maintainers. If a private reporting address is not yet published, open a GitHub issue asking for maintainer contact without disclosing sensitive details publicly.

Maintainers may remove comments, close issues, block users or take other appropriate action to protect the project community.

## Scope

This code of conduct applies in project repositories, discussions, issues, pull requests and other official project spaces.
